### Randomized-state generation

A separate named seeded RNG samples both HP buckets uniformly, then alive integer
HP within each; SP affordability bands uniformly, then integerSP; valid mental
status/duration and finite-use flags. Player RILED is excluded. Guard FOCUSED
requires Wife already used. Round defense and Guard incapacitation are cleared
in drafts. One real CombatSystem round then samples uniformly valid actions for
both actors, locks/reveals/resolves/ends normally. This establishes actual previous
action, coherent last-action costs/recovery, statuses/durations and finite-use
effects. Terminal or forced-Guard-skip results are rejected (bounded64 attempts).
The accepted state is a live, unlocked Guard decision state. Player stun is allowed
only as generated by actual Whistle and uses the real forced-null behavior.

Seed rounds are preparation, **not training steps**: no reward/Q update, no initial
HP-deficit reward. Both actors start alive, so no free terminal reward on reset.
All post-reset events and actual wins/losses use the SAME unchanged reward:
Player damage/20 -Guard damage/20 -.2 per resolved round; terminal+100/-100/-10.
Terminal reward remains appropriate to winning from the observed state; there is
no extra bonus for starting with a near-dead opponent and no reward normalization.
Normal/randomized training results are tracked separately; mixed training wins
must not be mistaken for full-battle evaluation performance.

Real seed rounds/rejection alter the accepted distribution; it is NOT claimed
uniform afterward. Reconstructing all recorded randomized starts gave all25 HP
pairs, including CRITICAL/CRITICAL=150,
CRITICAL/LOW=173, CRITICAL/HIGH=178,
VERY_HIGH/CRITICAL=190, LOW/LOW=189.
Coverage data: public/assets/ai/guard_start_coverage.json. No table or learning
is involved in reconstructing it.
