SCHOOL ESCAPE — RUNTIME SOUND EFFECTS

This folder contains the 36 selected sound files used by the game.
manifest.json records stable keys, original pack paths, hashes and measured metadata.
SFX volume settings are applied by src/game/audio/SoundEffects.js.

The original collection contained 500 effects. Unselected files, raw source copies
and candidate copies are not required to run the game and are no longer shipped.

All included WAV files are CC0. Keep LICENSES.txt for creator/source information.
Original filename suffixes and source IDs remain recorded in manifest.json.
Music is separate: ../MUSIC_LICENSE.md credits @prodbyhajime under CC BY4.0.

Game documentation: docs/SFX_INTEGRATION_REPORT.md and docs/SFX_MISSING.md.
